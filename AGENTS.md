# Project instructions

## Technical language

Use ASD-STE100 Simplified Technical English for all technical documents and code comments in this project. This requirement is mandatory for new and changed text.

- Apply the ASD-STE100 writing rules and approved dictionary.
- Use approved words with their specified meanings and parts of speech.
- Use technical nouns and technical verbs as permitted by ASD-STE100. Use each term consistently.
- Use active voice and simple verb forms.
- Give one instruction in each sentence. Use the imperative form for instructions.
- Use a maximum of 20 words per sentence in procedures and 25 words per sentence in descriptions.
- Put a necessary condition before its instruction.
- Preserve technical meaning, code identifiers, commands, file paths, and literal values.
- When you change existing text, make the changed text comply with this requirement.

Reference: [ASD-STE100](https://www.asd-ste100.org/).
